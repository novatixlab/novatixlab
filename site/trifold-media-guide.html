A0 – 128 px

A  좌측 날개 → 접으면 뒷면 오른쪽
B  정면 → 접어도 앞면 그대로
C  우측 날개 → 접으면 뒷면 왼쪽
뒤에서 보면 C + A 순서로 이어지므로, C존에 배너 왼쪽 절반 · A존에 오른쪽 절반을 넣으면 뒷면에서도 온전한 배너 한 장이 완성됩니다.
CHECKLIST
  1. 캔버스는 512 × 768 px로 제작 (고해상 작업 시 1280 × 1920 px 등 정배수 허용)
  2. 정면 노출용 콘텐츠는 중앙 B존(128 – 384 px) 안에 배치
  3. 접었을 때 뒷면에도 배너를 노출하려면 — A존에 배너의 오른쪽 절반, C존에 배너의 왼쪽 절반을 배치
  4. 접힘선(x = 128 px, 384 px) 위에 로고·텍스트를 걸치지 않기
  5. 최종 납품: 펼침용 512 × 768 파일 1개 — 접힘 상태의 앞·뒤는 자동으로 각 256 × 768로 표시
